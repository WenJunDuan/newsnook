# 需求: 本机阅读偏好驱动 AI 精选

## 原始用户故事

会话原话（不修饰）：

1. 「目前阅读历史有存储下来吗，包括新闻分类、媒体出品方都有保存吗」
2. 「能存储下的内容也存储下来，我要做一个阅读人的阅读偏好功能，设置放在AI精选设置里面，然后把配置项用类似条形和数字显示出来，后面基于每日阅读历史去精修阅读偏好，然后ai精选就着重去展示这些偏好新闻，偏好侧重在里面可以修改」
3. 「文档按照ai_state里面的要求存储下来，避免后期反查资料丢失；然后再去思考下我说的几个问题怎么去做和我确认下设计细节，然后再去动手」

作为读者，希望本机记住「我常读什么分类、哪些出品方」，在 AI 精选设置里看见并可改侧重，精选按这份画像挑稿；默认时间线不被改写。

## 当时的权衡 (为什么这样圈定范围)

- 要: 阅读事件落本机（分类 + 出品方可被偏好使用）；设置入口在 AI 精选/智读设置；条形 + 数字；每日阅读精修自动侧重；用户可改侧重；精选使用该画像。
- 不要: 账号/云同步、服务端推荐、改首页时间线排序、把「打开原文」当主路径。
- 取舍: 精选仍须用户主动触发、自备接口、本机计算画像。
- 已确认: 「分类」= 信源所属主题分类，「综合」不算兴趣分类。
- 已确认: 精选双路约 70/30；近 7 天+今日加权；拖动锁定；一天一篇一次。
- 后补: 模型接口放在「AI 助手 → 配置」；「智读与精选」只管开关/算法/偏好；画像每 4 小时按日志调整。

## 高层验收 (能力级, 非实现级)

- [x] 完整打开文章后，本机能追溯出品方；分类信息按确认后的归因规则可追溯
- [x] 「智读与精选」里能看到分类/出品方侧重（条形 + 数字）并允许修改
- [x] 自动侧重随阅读日志更新；用户改过的项锁定；画像每 4 小时重算
- [x] AI 精选使用该画像，且不改变默认时间线排序
- [x] 偏好与阅读记录只存本机
